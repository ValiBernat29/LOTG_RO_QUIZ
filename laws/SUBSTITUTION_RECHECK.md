# Rev19 — înlocuiri înaintea loviturii de pedeapsă

Reverificare la 16 octombrie 2026: ID 17, 18, 22 și 24.
Starea anterioară este păstrată în `rechecks-rev19.json`.

Verificare: [Legea 3 și FAQ IFAB](https://www.theifab.com/laws/latest/the-players/),
art. 3.3, și [protocolul de înlocuire limitată în timp](https://www.theifab.com/laws/latest/time-limited-substitution-protocol/).

Distincții de aplicare:

- ID 17 descrie alegerea altui înlocuitor când jocul este oprit pentru fault,
  înaintea efectuării schimbării. Nu descrie depășirea celor zece secunde.
  După acea depășire, protocolul interzice anularea înlocuirii sau schimbarea
  înlocuitorului, chiar dacă acesta nu a intrat încă. Regula nu se generalizează
  din răspunsul FAQ la toate schimbările nefinalizate.
- ID 18 privește permisiunea înlocuirii portarului înaintea LP. Disponibilitatea
  înlocuirilor/oportunităților și informarea arbitrului rămân obligatorii;
  nu se acordă o excepție automată de la protocolul de timp.
- ID 22 privește un apărător accidentat care nu poate continua. Permisiunea
  înlocuirii nu este anulată de protocol; arbitrul poate excepta limita când
  accidentarea împiedică ieșirea în timp.
- ID 24 privește dreptul unui înlocuitor deja intrat legal de a executa LP,
  nu dreptul de a ignora procedura intrării.

Pentru ID 18/22 se evidențiază condițiile intrării, fără propoziția despre
dreptul de a executa orice reluare. Pentru ID 17/24 acea propoziție rămâne
relevantă și este păstrată. Nu sunt modificate întrebări, răspunsuri sau citate;
ediția sursei românești rămâne 2025/26, separat de compatibilitatea 2026/27.

Total: 232 de situații asociate, dintre care 227 reverificate pentru 2026/27.
Rămân cinci asocieri pe 2025/26 (44, 45, 50, 217, 218) și 363 de situații
neasociate. Nu se marchează implicit niciuna dintre acestea ca finalizată.
Modificările sunt locale pe development, fără publicare.
